# johnjamieson.ca

The source of [johnjamieson.ca](https://johnjamieson.ca), John Jamieson's
website.

It's a static site built with [Astro](https://astro.build). The facts on it
come from John's master résumé, which he keeps privately as structured data.
They're copied in as `content/resume.json`. The site's own words are in
`content/site.yaml`. It sends no JavaScript to the browser and sets no
cookies.

- `ARCHITECTURE.md`: the design and its decisions.
- `BUILD.md`: how it's built, step by step.
